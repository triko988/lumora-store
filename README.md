# Lumora TN — GitHub Pages

نسخة متجر Lumora مخصصة للسوق التونسي.

### المزايا
- أسعار بالدينار التونسي.
- تصفية حسب الفئة.
- سلة شراء تعمل محلياً.
- الدفع عند الاستلام.
- نموذج طلب يجهز رسالة كاملة إلى بريد المتجر.
- متجاوب مع الهاتف.

### النشر
ارفع `index.html` إلى جذر مستودع GitHub، ثم:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

ملاحظة: GitHub Pages استضافة static؛ لا توجد قاعدة بيانات أو بوابة دفع داخل هذه النسخة.

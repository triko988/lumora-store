# Lumora Store

متجر Lumora جاهز للنشر على GitHub Pages.

## النشر
1. أنشئ Repository جديدًا على GitHub.
2. ارفع `index.html` إلى الفرع `main`.
3. Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main` و Folder: `/ (root)`.
6. Save.

## ملاحظة
الطلبات تُرسل عبر تطبيق البريد باستخدام `mailto:` إلى البريد الموجود داخل الموقع. هذا لا يوفر قاعدة بيانات أو دفعًا إلكترونيًا؛ لإنتاج متجر كامل مع دفع وقاعدة بيانات يلزم Backend/خدمة خارجية.
